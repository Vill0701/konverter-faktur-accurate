# Faktur Nama DPP PPN Total Status

Ringkasan

    Lengkapi langkah di samping terlebih dahulu.

    File XML siap!
    Unduh File XML

    Selanjutnya buka Accurate 5, gunakan menu Impor Transaksi, lalu pilih file yang baru diunduh.

    Lihat isi XML (untuk pengecekan teknis)

    Riwayat

    • Memuat riwayat…
    Semua data diproses di browser Anda sendiri dan tidak dikirim ke server mana pun. Riwayat hanya tersimpan di browser ini — akan hilang jika data browser dibersihkan.

    Cara Pakai

    1. Pilih jenis data. Keluaran A2 untuk penjualan Anda. Masukan untuk pembelian: B1 (impor/PIB), B2 (pembelian dalam negeri, PPN dikreditkan), B3 (PPN tidak dikreditkan). PPh 21 Gaji Karyawan untuk lampiran SPT Masa PPh 21: setiap bukti potong menjadi jurnal biaya gaji, hutang PPh 21, dan hutang gaji (GAJI.2026.01.001).
    2. Tentukan nomor urut. Bulan & tahun jurnal diambil otomatis dari kolom Masa Pajak, misalnya Masa Pajak Januari 2026 menjadi PENJ.2026.01.001. Anda cukup mengisi nomor urut awal. Jika sebelumnya sudah ada jurnal di bulan yang sama, lanjutkan nomornya agar tidak bentrok. File tanpa kolom Masa Pajak tetap bisa dipakai dengan memilih bulan & tahun sendiri.
    3. Isi nomor akun. Gunakan nomor akun persis seperti di daftar akun (Chart of Accounts) Accurate Anda.
    4. Unggah file Excel dari DJP/Coretax. Periksa tabel pratinjau: baris berstatus Dilewati tidak akan masuk ke jurnal beserta alasannya.
    5. Klik "Buat File XML", unduh filenya, lalu impor ke Accurate 5.

    Istilah

    DPP
    Dasar Pengenaan Pajak — nilai transaksi sebelum PPN.
    PPN
    Pajak Pertambahan Nilai atas transaksi.
    Debit / Kredit
    Sisi pencatatan jurnal. Total debit selalu sama dengan total kredit.
    Riwayat
    File XML yang pernah dibuat disimpan di browser ini saja. Di komputer atau browser lain riwayatnya berbeda, dan akan hilang jika data/cache browser dihapus. Simpan file XML penting di folder Anda.
    Dilewati
    Baris yang datanya tidak lengkap (mis. NPWP atau nomor faktur kosong) sehingga tidak dibuatkan jurnal.
    Retur
    Faktur dengan DPP/PPN bernilai minus. Jurnalnya dibalik (debit ↔ kredit) dan memakai Akun Retur Penjualan/Pembelian yang Anda isi sebagai pengganti Akun Penjualan/Pembelian.
    Bukti potong
    Bukti pemotongan PPh 21 satu penerima untuk satu masa pajak. Semua sheet lampiran PPh 21 yang berisi data (mis. Tabel 1A dan Lampiran 3 - BP21) ikut dibaca.
    Bruto / Neto
    Penghasilan bruto = gaji & tunjangan sebelum dipotong PPh 21, dicatat sebagai Biaya Gaji. Neto = bruto − PPh 21, yaitu gaji yang dibayarkan, dicatat sebagai Hutang Gaji.
