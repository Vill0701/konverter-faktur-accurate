# Faktur Nama DPP PPN Total Status

Ringkasan

    Lengkapi langkah di samping terlebih dahulu.

    File XML siap!
    Unduh File XML

    Selanjutnya buka Accurate 5, gunakan menu Impor Transaksi, lalu pilih file yang baru diunduh.

    Lihat isi XML (untuk pengecekan teknis)

    Riwayat

    • Memuat riwayat…
    Semua data diproses di browser Anda sendiri dan tidak dikirim ke server mana pun. Riwayat hanya tersimpan di browser ini — akan hilang jika data browser dibersihkan.

    Cara Pakai

    1. Pilih jenis faktur. Keluaran untuk penjualan Anda. Masukan untuk pembelian: B1 (impor/PIB), B2 (pembelian dalam negeri, PPN dikreditkan), B3 (PPN tidak dikreditkan).
    2. Tentukan periode. Pilih bulan & tahun jurnal. Nomor urut menentukan nomor bukti pertama, misalnya PENJ.25.10.001. Jika sebelumnya sudah ada jurnal di bulan yang sama, lanjutkan nomornya agar tidak bentrok.
    3. Isi nomor akun. Gunakan nomor akun persis seperti di daftar akun (Chart of Accounts) Accurate Anda.
    4. Unggah file Excel dari DJP/Coretax. Periksa tabel pratinjau: baris berstatus Dilewati tidak akan masuk ke jurnal beserta alasannya.
    5. Klik "Buat File XML", unduh filenya, lalu impor ke Accurate 5.

    Istilah

    DPP
    Dasar Pengenaan Pajak — nilai transaksi sebelum PPN.
    PPN
    Pajak Pertambahan Nilai atas transaksi.
    Debit / Kredit
    Sisi pencatatan jurnal. Total debit selalu sama dengan total kredit.
    Riwayat
    File XML yang pernah dibuat disimpan di browser ini saja. Di komputer atau browser lain riwayatnya berbeda, dan akan hilang jika data/cache browser dihapus. Simpan file XML penting di folder Anda.
    Dilewati
    Baris yang datanya tidak lengkap (mis. NPWP atau nomor faktur kosong) sehingga tidak dibuatkan jurnal.
